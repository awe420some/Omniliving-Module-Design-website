# Omniliving Module Design Website

Dieses Projekt ist eine interaktive Web-Anwendung für das Modul-Design von Omniliving.

## Installation und lokaler Start

Folgen Sie diesen Schritten, um das Projekt lokal auf Ihrem Rechner einzurichten und zu starten:

1. **Ordner erstellen**: Erstellen Sie einen neuen Ordner auf Ihrem System für das Projekt.
2. **Terminal öffnen**: Starten Sie Ihr Terminal oder Ihre Kommandozeile.

3. **Verzeichnis wechseln**: Navigieren Sie mit dem `cd`-Befehl in den Projektordner:
   ```bash
   cd /pfad/zu/ihrem/projektordner 
   ```
	z.B 
   ```bash
	cd /Users/Benutzer/Desktop/Omniliving-Module-Design-GmbH
   ```

4. **Abhängigkeiten installieren**: Führen Sie den folgenden Befehl aus, um alle notwendigen Pakete zu installieren:
   ```bash
   npm install
   ```
5. **Entwicklungsserver starten**: Starten Sie die Anwendung mit:
   ```bash
   npm run dev
   ```
6. **Anwendung aufrufen**: Öffnen Sie Ihren Browser und navigieren Sie zu [http://localhost:3000](http://localhost:3000).

## Deployment

Wenn Sie die Anwendung online verfügbar machen möchten (Deployment), haben Sie verschiedene Möglichkeiten:

* **Vercel**: Ideal für Next.js Projekte (einfache Integration via GitHub).
* **Eigener Server**: Hosting auf einem VPS oder dedizierten Server.
* **Andere Provider**: Plattformen wie Netlify oder AWS.

Nach dem Deployment verbinden Sie die Anwendung einfach mit Ihrer gewünschten Domain/URL.
